# Команды

На подготовленном Linux-агенте (справочно, здесь не выполнено):

```bash
cd src/app
go test .
docker build -t sdvps-demo:local .
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o main-local .
```

Проверка shell без исполнения: `bash -n src/freestyle.sh`. Для полного Jenkins lint нужен работающий Jenkins с Declarative plugin; в текущем локальном режиме он не запускается. Публикация и запуск облака не требуются.
