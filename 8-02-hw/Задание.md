# Что такое DevOps. CI/CD

[Кабинет](https://netology.ru/profile/program/cicd-62/lessons/656571/lesson_items/3523483), открыт 27 октября 2026; явно самостоятельная работа без проверки экспертом. [Условие по ссылке кабинета](https://github.com/netology-code/sdvps-homeworks/blob/main/8-02.md).

1. Jenkins на машине (Docker нежелателен), Go, fork sdvps-materials, Freestyle с `go test .` и `docker build .`, снимки настройки/результатов.
2. Перенести сборку в Declarative Pipeline, снимки настройки/результата.
3. Nexus, raw-hosted, заменить Docker-сборку сборкой Go-бинарника, загрузить через Jenkins, снимки настройки/результата.
4*. Версионирование имени с BUILD_NUMBER.

Пользователь для самостоятельных выбрал локальное оформление без VM и отправки. Из недостающих новых доказательств готовим только подписанный учебный пример.
