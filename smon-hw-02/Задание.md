# Система мониторинга Zabbix

[Кабинет](https://netology.ru/profile/program/smon-62/lessons/668959/lesson_items/3583824), прочитано 27 октября 2026. Явно самостоятельное без эксперта.

1. Установить Zabbix Server с PostgreSQL и Apache, составить команды по официальному конфигуратору последней версии; приложить команды и авторизацию frontend.
2. Два агента Linux (один можно на сервере), разрешить сервер, добавить в Hosts, получить Latest data. В ответе нужны Hosts, журнал связи, Latest data обоих и команды.
3*. Windows-агент, свободное место C:, необязательно — не выбран.

По согласованному локальному режиму без VM: команды/конфигурации и подписанная схема, без заявлений о реальном подключении агентов. Публикация/отправка не выполняются.
