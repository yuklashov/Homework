# Установка и проверки — справочно

[src](../src/zabbix_agentd-host2.conf.example) задаёт только учебные адреса; не копировать без замены. [server-reference.sh](server-reference.sh) не запускался, предназначен для отдельной чистой Debian 12. Пакеты одной версии сервера и SQL-схемы, импорт в пустую БД ровно один раз. Пароль через интерактивный createuser/sudoedit; старый одинаковый пароль zabbix больше не используется.

На второй Linux-хост добавить тот же официальный репозиторий, затем:

```bash
sudo apt update
sudo apt install -y zabbix-agent
sudoedit /etc/zabbix/zabbix_agentd.conf
sudo systemctl enable --now zabbix-agent
sudo systemctl restart zabbix-agent
sudo journalctl -u zabbix-agent --since '-10 min'
sudo tail -n 50 /var/log/zabbix/zabbix_agentd.log
```

На сервере для пассивных проверок (адреса — документальные примеры):

```bash
zabbix_get -s 192.0.2.11 -k agent.ping
zabbix_get -s 192.0.2.11 -k system.uptime
```

Сетевые ACL: TCP10050 от Zabbix-сервера к агентам; TCP10051 от агентов к серверу для активных проверок; frontend только оператору. В частном учебном сегменте сначала проверить связь, для пересечения недоверенной сети добавить TLS PSK/сертификаты и настройки host Encryption. Установку Windows 3* не выбирали.
