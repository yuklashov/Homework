# Мануал по выполнению ДЗ «Система мониторинга Zabbix» (smon-hw-02)

## Цель домашнего задания:
Научиться устанавливать Zabbix Server с веб-интерфейсом и СУБД PostgreSQL, а также настраивать Zabbix Agent на серверах для сбора метрик.

## Задание 1. Установка Zabbix Server

### Действия
Все ресурсы (ВМ для Zabbix) поднимаются с ОС Debian 11. 
Для автоматизации и исключения ручных действий (согласно правилам IaC) использовался следующий набор bash-команд для полной установки Zabbix Server 6.0 LTS с PostgreSQL и Apache:

```bash
# 1. Установка репозитория Zabbix
wget https://repo.zabbix.com/zabbix/6.0/debian/pool/main/z/zabbix-release/zabbix-release_6.0-4+debian11_all.deb
sudo dpkg -i zabbix-release_6.0-4+debian11_all.deb
sudo apt update

# 2. Установка сервера, фронтенда, агента и БД
sudo apt install -y zabbix-server-pgsql zabbix-frontend-php php7.4-pgsql zabbix-apache-conf zabbix-sql-scripts zabbix-agent postgresql

# 3. Настройка PostgreSQL
sudo -u postgres psql -c "CREATE USER zabbix WITH PASSWORD 'zabbix';"
sudo -u postgres createdb -O zabbix zabbix

# 4. Импорт исходной схемы базы данных
zcat /usr/share/zabbix-sql-scripts/postgresql/server.sql.gz | sudo -u zabbix psql zabbix

# 5. Настройка пароля БД в конфигурационном файле Zabbix
sudo sed -i 's/# DBPassword=/DBPassword=zabbix/' /etc/zabbix/zabbix_server.conf

# 6. Запуск и добавление в автозагрузку
sudo systemctl restart zabbix-server zabbix-agent apache2
sudo systemctl enable zabbix-server zabbix-agent apache2
```

### Результат
Zabbix Server успешно запущен. Веб-интерфейс доступен по адресу `http://<ip_вашего_сервера>/zabbix`. Логин по умолчанию: `Admin`, пароль: `zabbix`.

## Задание 2. Установка Zabbix Agent

### Действия
Первый агент уже установлен вместе с сервером на первой машине (он мониторит сам сервер).
Для установки на вторую машину (хост 2) выполнялся следующий скрипт:

```bash
# 1. Установка репозитория Zabbix
wget https://repo.zabbix.com/zabbix/6.0/debian/pool/main/z/zabbix-release/zabbix-release_6.0-4+debian11_all.deb
sudo dpkg -i zabbix-release_6.0-4+debian11_all.deb
sudo apt update

# 2. Установка агента
sudo apt install -y zabbix-agent

# 3. Настройка агента (замените IP-адрес на IP вашего Zabbix-сервера)
ZABBIX_SERVER_IP="192.168.1.100" # <-- ВАШ IP ZABBIX SERVERA
sudo sed -i "s/Server=127.0.0.1/Server=$ZABBIX_SERVER_IP/" /etc/zabbix/zabbix_agentd.conf
sudo sed -i "s/ServerActive=127.0.0.1/ServerActive=$ZABBIX_SERVER_IP/" /etc/zabbix/zabbix_agentd.conf
sudo sed -i "s/Hostname=Zabbix server/Hostname=ZabbixAgent-Host2/" /etc/zabbix/zabbix_agentd.conf

# 4. Перезапуск агента
sudo systemctl restart zabbix-agent
sudo systemctl enable zabbix-agent
```

### Результат
Оба агента добавлены в разделе **Configuration > Hosts**. В разделе **Monitoring > Latest data** пошли метрики.
Для сдачи вам необходимо прикрепить скриншоты:
1. Авторизации в админке.
2. Списка хостов (Configuration > Hosts).
3. Данных мониторинга (Latest data).
