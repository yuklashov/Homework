# Команды

Проверка в отдельном временном каталоге, без облака:

```bash
work_dir=$(mktemp -d /tmp/netology-tf-demo.XXXXXX)
cp src/main.tf "$work_dir/main.tf"
terraform -chdir="$work_dir" fmt -check
terraform -chdir="$work_dir" init -backend=false -input=false
terraform -chdir="$work_dir" validate
terraform -chdir="$work_dir" plan -input=false -lock=false
```

Для архивного провайдера используется `src/provider-example/main.tf`; загрузка AWS-плагина и обращение к AWS в этом сеансе не выполнялись. Не помещать ключи API в HCL. Рабочие команды `apply`/`destroy` здесь не нужны.
