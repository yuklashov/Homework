# Проверки

Выполнено:

```bash
bash -n src/home-backup.sh
python3 scripts/verify_local.py
```

Справочно для отдельного учебного Linux (здесь не выполнено):

```bash
mkdir -p "$HOME/bin"
# Поместить проверенный скрипт в ~/bin/home-backup.sh.
# Сначала проба на временном источнике/назначении.
crontab -e
# Внести расписание из src/crontab.example с действительным абсолютным путём.
journalctl -t netology-home-backup --since today
```

Не заменять действующий crontab целиком. Из-за --delete целевой /tmp/backup должен принадлежать этой учебной копии; не выбирать каталог с чужими файлами.
