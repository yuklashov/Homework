# Кластеризация и балансировка

[Кабинет](https://netology.ru/profile/program/sflt-62/lessons/692933/lesson_items/3704979), прочитано 27 октября 2026. Самостоятельное, не проверяет эксперт.

1. Два Python HTTP-сервера на разных портах одной VM, HAProxy round-robin на L4, конфиг и кадры разных backend.
2. Три сервера, L7 weighted round-robin с весами 2/3/4; балансировать только Host example.local, показать запросы с ним и без него.
3*. Nginx отдаёт jpg, остальные запросы через HAProxy к двум backend. 4*. Четыре сервера и два backend для example1.local/example2.local. Дополнительные не выбраны.

По поручению пользователя самостоятельная работа завершена локально: конфиги, объяснения и учебная модель/иллюстрация; без VM/отправки и без подмены модели реальными свидетельствами.
