# Команды

Выполнена только математическая модель:

```bash
python3 scripts/model.py
```

На отдельном подготовленном Linux (здесь не выполнено), из папки решения:

```bash
# Три отдельных терминала; завершить каждый Ctrl+C.
python3 -m http.server 8001 --bind 127.0.0.1 --directory src/web1
python3 -m http.server 8002 --bind 127.0.0.1 --directory src/web2
python3 -m http.server 8003 --bind 127.0.0.1 --directory src/web3
# Проверить конфиги, затем запускать в отдельных терминалах:
haproxy -c -f src/haproxy-l4.cfg
haproxy -c -f src/haproxy-l7.cfg
haproxy -db -f src/haproxy-l4.cfg
haproxy -db -f src/haproxy-l7.cfg
```

Проверки отдельных соединений:

```bash
for i in $(seq 1 20); do curl --silent --show-error --fail -H 'Connection: close' http://127.0.0.1:8080/; done
for i in $(seq 1 90); do curl --silent --show-error --fail -H 'Host: example.local' -H 'Connection: close' http://127.0.0.1:8081/; done
curl --include -H 'Host: other.local' http://127.0.0.1:8081/
curl --include http://127.0.0.1:8081/
curl --resolve example.local:8081:127.0.0.1 http://example.local:8081/
```

Указанные порты слушают только loopback; новых firewall/DNS/hosts-правил для примера не требуется. Ожидаемый отказ для wrong Host — 403, но реальный HTTP-тест этим сеансом не выполнялся.
