# IPv6 — проверено существующее решение

[Готовый Google Doc Александра Юклашова](https://docs.google.com/document/d/1Jnay1QeGovJ0Ot8FqEZC94IHuVkmK-0HDVV-gK22M1c/edit?usp=drivesdk).

26 октября 2026 года старое решение сверено с [условием, на которое ссылается текущий урок NET-62](https://github.com/netology-code/snet-homeworks/blob/snet-15/4-13.md). Документ содержит ответы на все пять пунктов. Переписывать работу не требуется.

| Пункт | Что требуется | Что найдено |
|---|---|---|
| 1 | Нотация IPv6, символы и разделители | Описаны 128 бит, восемь групп, шестнадцатеричная запись и двоеточия |
| 2 | Loopback-адрес | Приведён ::1 и полная запись |
| 3 | Unicast, Multicast, Anycast | Даны объяснения способов доставки |
| 4 | Получить IPv6 ресурса командой Linux и приложить снимок | Визуально проверен настоящий снимок dig google.com AAAA и host -t AAAA google.com в Ubuntu с результатами |
| 5 | Интернет-маршрутизируемые и локальные адреса | Объяснены Global Unicast, Link-Local и ULA с префиксами |

Просмотр по ссылке проверен по разрешениям Drive: anyone/reader, поиск документа отключён. Комментарии Drive отсутствуют; это не доказывает отсутствие замечаний в старом личном кабинете.

Текущий статус платформы — «Выполнить», прежний зачёт и его перенос не подтверждены. Условие NET-62 открыто для сравнения; до открытия указан срок 5 дней. В разделе отправки поле ответа отсутствует. Повторная отправка не выполнялась. Вопрос направлен в поддержку с разрешения пользователя.
