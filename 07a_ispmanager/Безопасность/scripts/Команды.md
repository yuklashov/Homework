# Команды для отдельного Linux-стенда — здесь не выполнены

```bash
# После согласованной установки ClamAV и обновления баз:
clamscan --infected /var/www/user-a/data/www/a.example.test/private/index.html
# Код 0: угроз не найдено; 1: найдена; 2: ошибка проверки.
sshd -t
sshd -T
fail2ban-client -t
fail2ban-client status
fail2ban-client status sshd
ss -lntp
```

Не выполнять restart SSH до проверки нового пользователя/ключа и правил доступа. Предложенные файлы — фрагменты для рассмотрения, не автоскрипт изменения сети. Реальный IP оператора хранить локально, не в отчёте. Mac/VPN/Happ не меняются.
