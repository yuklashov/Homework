# Установка ispmanager на Linux

[Кабинет](https://netology.ru/profile/program/ispm-62/lessons/658411/lesson_items/3531469), полное условие прочитано 27 октября 2026. Самостоятельное, без эксперта, 120 минут.

Установить ispmanager официальным скриптом: stable → рекомендуемое ПО → Nginx + Apache (MPM-ITK) → SQLite. Войти, активировать лицензию, выполнить базовые настройки. Создать администратора-суперпользователя, администратора и пользователя. Для user: диск 2000 МБ, две БД; разрешить SSL, PHP-модуль Apache и shell; запретить CGI, PHP CGI, PHP-FPM Nginx, CRON, DNS и резервные копии. Требуются снимки root/admin/user в шаблоне.

Пользователь заменил самостоятельную отправку локальным оформлением без VM. Ответ и полный список полей записаны в README, учебный экран явно подписан. Установки/активации и реальных снимков не заявляем.
