# Справочные команды, не выполнены

Только на чистом согласованном Linux-стенде, с root:

```bash
cat /etc/os-release
uname -m
hostnamectl
timedatectl
df -h
free -h
wget https://download.ispmanager.com/install.sh -O install.sh
less install.sh
sh install.sh
# Выбор: stable; рекомендуемое ПО; Nginx+Apache ITK; SQLite.
# После установки проверить службы и вход HTTPS, не отключая проверку сертификата.
systemctl status ihttpd --no-pager
ss -lntp
```

Облачный запуск, покупка лицензии, реальные пароли/аккаунты в этой работе не выполнялись. Установочный скрипт на Mac не загружался и не запускался. Названия пунктов и службы сверять с выбранной версией при реальном развёртывании.
