# Команды и проверки

Выполнена безопасная модель:

```bash
python3 scripts/model_restore.py
```

Справочно на отдельном учебном Linux (не выполнено):

```bash
# Пароль вводится интерактивно, не в командной строке.
mysqldump --single-transaction -u wp_user -p wp_database > /private/backup/wp_database.sql
mysql -u wp_user -p wp_database < /private/backup/wp_database.sql
# SELECT по нужной таблице, проверка URL/текста сайта и журналов.
curl --fail --show-error https://wp.example.test/
```

Путь /private/backup здесь условный; заранее создать защищённый каталог за пределами docroot. Удаление настоящих пользователей и данных команды не выполняют. В панели сначала выбрать завершённую копию и состав восстановления, затем проверить результат.
