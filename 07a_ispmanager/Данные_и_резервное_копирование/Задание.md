# Работа с данными и резервное копирование

[Кабинет](https://netology.ru/profile/program/ispm-62/lessons/658413/lesson_items/3531489), прочитано 27 октября 2026. 90 минут, самостоятельное без эксперта.

Создать netology/ispmanager без автообъектов, все доступы кроме shell. WordPress у netology, скачать файлы и дамп, создать системную копию. Удалить файлы+БД, восстановить из скачанных, передать сайт ispmanager. Удалить ispmanager с ресурсами, восстановить из системной копии первоначального netology; проверить владельца и работу. В шаблоне шесть снимков: пользователи, исходный сайт, копия netology, новый владелец, отсутствие ispmanager, восстановленный сайт у netology.

Вместо новых настоящих снимков пользователь для самостоятельных выбрал локальные примеры: все этапы разобраны, SVG подписан; реальная панель не заявлена. Сторонний домен netology.ru из иллюстративного пути условия заменён учебным wp.example.test.
