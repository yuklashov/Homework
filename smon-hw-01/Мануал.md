# Инструкция к ДЗ smon-hw-01

## Настройка через Terraform

Это домашнее задание было выполнено с использованием Terraform для развертывания виртуальной машины и дашборда мониторинга в Yandex.Cloud.

### Предварительные требования

- Аккаунт в Yandex.Cloud
- Установленный и настроенный `yc` CLI
- Установленный Terraform

### Использование

1.  Перейдите в директорию `Homework/smon-hw-01`.
2.  Создайте файл `terraform.tfvars` с вашими учетными данными Yandex.Cloud:

    ```
    yc_token     = "ВАШ_YC_TOKEN"
    yc_cloud_id  = "ВАШ_CLOUD_ID"
    yc_folder_id = "ВАШ_FOLDER_ID"
    ssh_key_public = "ВАШ_ПУБЛИЧНЫЙ_SSH_КЛЮЧ"
    ```

3.  Инициализируйте Terraform:
    ```bash
    terraform init
    ```

4.  Примените конфигурацию:
    ```bash
    terraform apply
    ```

Это создаст ВМ и дашборд в вашем аккаунте Yandex.Cloud.

## Ручная настройка алертов

Алерты мониторинга (WARN и ALARM) и канал уведомлений не удалось создать с помощью Terraform из-за ограничений в провайдере Yandex.Cloud и CLI в используемом окружении.

Эти ресурсы были настроены вручную в веб-консоли Yandex.Cloud согласно инструкции к домашнему заданию.

В качестве альтернативы, вы можете использовать `yc` CLI для их создания:

1.  **Создание канала уведомлений:**
    ```bash
    yc monitoring channel create email-channel --email ВАШ_EMAIL@example.com --format json
    ```
    (Запомните `id` из вывода)

2.  **Создание алертов:**
    ```bash
    # Алерт WARN
    yc monitoring alert create --name="cpu-warn" --metric-query="cpu_utilization{service=\\"compute\\", resource_id=\\"ID_ВАШЕЙ_ВМ\\"} > 80" --evaluation-delay="1m" --notification-channel-id=ID_ВАШЕГО_КАНАЛА --warn-threshold=80

    # Алерт ALARM
    yc monitoring alert create --name="cpu-alarm" --metric-query="cpu_utilization{service=\\"compute\\", resource_id=\\"ID_ВАШЕЙ_ВМ\\"} > 90" --evaluation-delay="1m" --notification-channel-id=ID_ВАШЕГО_КАНАЛА --alarm-threshold=90
    ```

Замените `ВАШ_EMAIL@example.com`, `ID_ВАШЕЙ_ВМ` и `ID_ВАШЕГО_КАНАЛА` на ваши реальные значения.
