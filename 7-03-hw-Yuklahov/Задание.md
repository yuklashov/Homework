# Подъём инфраструктуры в облаке

[Кабинет](https://netology.ru/profile/program/cicd-62/lessons/656569/lesson_items/3523477), условие открыто 27 октября 2026. Самостоятельная практика, эксперт не проверяет.

1. Повторить демонстрацию: VPC, два web-сервера и bastion.
2. Подключиться к web-a/web-b через Ansible, установить Nginx, приложить снимки VM и успешного playbook.

Дополнительно 3*: ещё одна VM с БД и проверка служб. 4*: передавать токен через YC_TOKEN, убрав token из провайдера. Необязательный пункт 3 не выбран; способ 4 описан в командах, новый облачный pipeline не заявлен. По соглашению с пользователем самостоятельная работа оформляется локально без отправки и VM.
