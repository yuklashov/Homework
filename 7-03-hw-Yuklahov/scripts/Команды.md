# Команды

Выполнены только `terraform fmt`, `init -backend=false` с уже установленным провайдером, `validate` во временной копии, `ansible-playbook --syntax-check`. Это не подключение к облаку.

Справочный порядок будущего согласованного запуска, здесь не выполнен:

```bash
# Локальный файл переменных: cloud/folder, публичный SSH-ключ, operator_cidr=/32.
# Токен не выводить, не помещать в tfvars и не добавлять автогенерацию в ~/.bashrc.
export YC_TOKEN="$(yc iam create-token)"
terraform -chdir=src init
terraform -chdir=src plan -var-file=/absolute/private/lab.tfvars -out=/absolute/private/lab.plan
# apply/destroy выполняет пользователь после согласования бюджета.
# После создания обновить адрес бастиона и known_hosts; пройти проверку ключей.
ansible-playbook -i /absolute/private/inventory.ini src/ansible/playbook.yml
unset YC_TOKEN
```

NAT gateway/диски/VM могут тарифицироваться отдельно: удалить все ресурсы после реального окна, если оно будет согласовано. Адрес оператора держать в .local, не менять маршруты Happ и не отключать VPN. Для нового стенда дополнить cloud-init диагностикой serial, как описано в AGENTS.md; текущая работа не запускается.
