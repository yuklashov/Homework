# Команды и состояния Git

Справочный порядок, новые коммиты не выполнялись:

```bash
git status
git diff
git add README.md
git diff --staged
git commit -m 'First commit'
git switch -c dev
# редактирование test.sh, git add и осмысленные коммиты
git switch main
git merge dev
git log --graph --oneline --all
# При конфликте: отредактировать test.sh, убрать маркеры,
# git add test.sh; git commit завершает merge.
```

Проверка архива выполнена командами только чтения: `git log --all --graph` и `git show <commit>:8-01-hw/test.sh`. Исторический граф подтверждает операции, повторять их в основном рабочем репозитории не следует.
